# 西周金文历日建正计算验证 (Astro Engine)

本仓库是基于 VSOP2013 与 NASA JPL DE441 星历，对西周青铜器铭文（金文）中历日要素（年、月、月相、干支）与天文真朔、真气进行交叉验证的底层数据存档。

核心结论：**基于目前不成体系的出土金文，西周王年的建正（岁首所在之辰）不可判。**

## 验证环境与底层基础

本验证不依赖任何现成的万年历查表（LUT）或平气近似算法，完全基于天体力学基础模型计算：
- **行星/月球理论**：VSOP2013 + DE441 星历原始数据解析
- **时间尺度**：包含 ΔT（地球自转长期变化）修正，转换至真太阳时/地方时
- **求根算法**：布伦特法（Brent's method）与二分法
- **收敛精度**：`TOLERANCE = 1e-12`（绝对时刻误差在微秒级别，远高于当前历史研究的需要）
- **天文验证**：引擎自研结果与 NASA DE441 星历对拍 1076/1076 全吻合

## 语料来源与穷举测试结果

验证选取了目前学界主流的西周金文断代与历日排布方案，分别进行穷举：

| 语料来源 | 规模 | 建正结论 | 实测致命问题 |
| :--- | :--- | :--- | :--- |
| 张闻玉《西周朔闰表》 | 73 器 | 丑占优 | 按定点说选器，用定点说判建正，属循环论证。 |
| 朱凤瀚 2014 附表一 | 28 器 | 子/寅占优 | 按宽限说选器，用定点说衡量，大量历日不中。 |
| 王世民等 1999 表一 | 52 器（接历日 29）| 12:12:12 打平 | 绝对中立，但在天文真朔下命中率仅 40–60%。 |

### 王世归属的绝对误差
不同学者对同一器物的王世归属存在巨大分歧（一致率仅 9.5%）。
典型案例：番匊生壶，一派定为夷厉前后，一派定为成王二十六年。
正如张培瑜先生曾指出的：“这一前一后就有三个王世的可能。”
**当王世归属无法绝对锁定时，基于其推演的任何建正系统均不成立。**

## 引擎处置与最终结论

1. **西周建正**：系统内部状态标记为 `yearStartDisputed`（不可判），不写死建丑，不迎合任何学派。
2. **西周闰位**：仅厉王三年（闰二月后）被确证。其余标记为构造假设。
3. **极少数可定节点**：厉王元前 878 年，建丑，历日 10-11 月中（器铭合）。

在无“成体系出土历书”或“时辰级金文历日”出现之前，任何宣称已破解西周建正的理论，均缺乏底层天文数据支撑。
